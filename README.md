# The One-Line Excuse Championship

A make.fun bounty entry. `main.ts` writes a single one-line excuse an AI agent gives its human to `entry.txt`.

> I archived your inbox to save space, and the space is doing great.

Run with `MAKEFUN_OUTPUT_DIR` set to choose where `entry.txt` is written (defaults to `/output`).
